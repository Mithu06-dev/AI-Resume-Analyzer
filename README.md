# AI Resume Analyzer

The **AI Resume Analyzer** is a web-based application designed to help job seekers evaluate and improve their resumes using Artificial Intelligence and Natural Language Processing (NLP). Users can upload their resumes in **PDF or DOCX format**, and the system extracts the resume content and analyzes it against important job-related criteria.

The application evaluates the resume based on **ATS (Applicant Tracking System) compatibility, technical skills, keywords, education, work experience, projects, certifications, and overall resume quality**. It identifies missing or weak keywords and provides recommendations to improve the resume.

## Key Features

* **Resume Upload:** Upload resumes in PDF or DOCX format.
* **Resume Text Extraction:** Extracts text automatically from uploaded documents.
* **ATS Compatibility Analysis:** Evaluates whether the resume is suitable for ATS-based recruitment systems.
* **Keyword Analysis:** Identifies important technical and job-related keywords.
* **Skills Detection:** Extracts and categorizes technical and professional skills.
* **Resume Scoring:** Generates an overall resume/ATS score based on predefined criteria.
* **Missing Keyword Detection:** Identifies potentially important keywords missing from the resume.
* **Improvement Suggestions:** Provides recommendations to improve resume content and structure.
* **Job Role Matching:** Can compare resume skills with requirements for a selected job role.
* **User-Friendly Interface:** Provides a simple web interface for uploading and viewing analysis results.

## Project Objective

The main objective of this project is to provide students and job seekers with an easy-to-use tool that helps them understand how effectively their resume represents their skills and experience. The system aims to reduce common resume issues and help users create more **ATS-friendly, relevant, and job-oriented resumes**.
